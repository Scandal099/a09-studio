1. Общие положения

Настоящая политика определяет порядок обработки персональных данных пользователей сайта A/09 в соответствии с Федеральным законом № 152-ФЗ.

2. Какие данные собираются

Только сведения из формы заявки: имя, контакт для связи (Telegram, телефон или email), выбранный формат и комментарий, если вы его указали.

3. Цель обработки

Данные используются только для ответа по вашему сайту, оценки стоимости и подготовки простого договора. Контакты не передаются третьим лицам и не используются для рассылок.

4. Хранение и защита

Данные заявок хранятся ровно столько, сколько нужно для переписки и работы по проекту, либо до вашего запроса на удаление.

5. Удаление данных

Для удаления данных напишите на hello@a09.studio с темой «Удаление данных» — запрос будет выполнен за 3 рабочих дня.
