# А/09 — Сайты, редизайн и внедрение CRM для бизнеса

Минималистичный многостраничный монохромный сайт студии (`#0b0b0b` / `#f2f2f2`) на чистом Next.js 16 (App Router) для российского хостинга с мгновенной пересылкой заявок в Telegram-бота и локальным резервным логированием заявок и согласий (152-ФЗ).

> Предыдущая корпоративная B2B-версия сохранена в git-теге `v-b2b-full`.

## Архитектура и маршруты
- **Стек:** Next.js 16 (App Router) + React 19 + TypeScript + Zod + локальные шрифты `Onest Variable` и `JetBrains Mono Variable` (без внешних CDN).
- **Маршруты:**
  - `/` — главная витрина студии (оффер, скульптурный знак, обзор 4 основных форматов, акцентный блок и переходы в разделы);
  - `/services` — основные форматы под ключ (лендинги, многостраничные сайты, редизайн, внедрение CRM и интеграции) + сравнение с конструкторами;
  - `/catalog` — каталог 12 отдельных услуг и модулей с фильтрами по категориям (внедрение Битрикс24/amoCRM, Telegram-бот, онлайн-запись, калькулятор, оплата, перенос с конструктора, ускорение и др.) и заказом каждой услуги в один клик;
  - `/cases` — 3 стартовых слота со скидкой 15% и блок бесплатного разбора сайта со списком правок;
  - `/process` — 4 этапа работы, гарантии 50/50, блок прямой работы с автором и ответы на 7 частых вопросов;
  - `/contact` — каналы связи, график, реквизиты и встроенная форма заявки;
  - `/privacy` — Политика обработки персональных данных (152-ФЗ);
  - `/consent` — отдельный документ Согласия на обработку ПДн (156-ФЗ);
  - `/en` — перенаправление на `/` (англоязычная версия отключена до запуска международного направления);
  - `/api/inquiries` — защищённый серверный приём заявок (Zod `.strict()`, rate limit, honeypot, проверка Origin, запись в локальный журнал на сервере РФ и мгновенная отправка в Telegram-бот).

## Что заполнить перед запуском рекламы
1. **Реквизиты и контакты** — в верхней секции файла `studio/content.ts`:
   - `TELEGRAM_HANDLE` (логин Telegram без `@`), `WHATSAPP_NUMBER`, `PHONE_DISPLAY`/`PHONE_HREF`, `CONTACT_EMAIL`;
   - `studioContact.legal`: ФИО самозанятого (НПД), ИНН, город/адрес для корреспонденции, номер в Реестре РКН (после подачи уведомления на `pd.rkn.gov.ru`).
2. **Переменные окружения** — скопируйте `.env.example` в `.env.local` (или задайте в панели российского хостинга):
   - `NEXT_PUBLIC_SITE_URL`, `ALLOWED_ORIGINS`;
   - `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`;
   - `NEXT_PUBLIC_YM_ID` (при подключении Яндекс Метрики).
3. **Кейсы** — в `studio/content.ts` (`work.slots`) после первого реального проекта переключите `status: "open"` на `"published"` и добавьте скриншот/ссылку.

## Команды
- `npm install` — установка зависимостей
- `npm run dev` — локальная разработка (`http://localhost:3000`)
- `npm run lint` — проверка ESLint
- `npm run typecheck` — проверка TypeScript
- `npm run build` — production-сборка Next.js
- `npm run start` — запуск production-сервера на Node.js
